# 2026-09-17 · 기록 0건 화면의 첫 러닝 시작 CTA (#122)

`src/app/records/page.tsx` 의 빈 상태에 안내와 CTA 를 얹으면서 `docs/04-features.md` ·
`docs/07-screens.md` · 정본 디자인과 갈라진 것들. `docs/01~07` 은 고치지 않았다.

#43 · #44 가 확정한 빈 상태 결정(문구 · 랭킹 탭과 같은 배치 · 누적 러닝 · 개인 최고 기록 카드의
`0.0` · `0:00:00` · `--'--"` 표기)은 **그대로 두고 그 아래에 덧붙이기만 했다.**

## 1. 기록 0건 빈 상태에 안내 한 줄과 러닝 시작 CTA 가 생겼다

- **문서**: `docs/04-features.md:22` F7 「예외」 칸과 `docs/07-screens.md:27` 은 빈 상태를
  「"아직 기록이 없습니다" 등 빈 상태 화면 표시, 누적 거리 두 값은 0으로 표시」로만 정의한다.
  **다음에 무엇을 하라는 안내가 없다.** 정본 디자인 `탄천런.dc.html:879-920` 의 「러닝 기록」
  섹션에는 빈 상태 자체가 없다(#44 에서 확인된 사실).
- **디자인 · 구현**: 문구("아직 기록이 없습니다")와 배치는 #44 가 확정한 그대로 두고, 그 아래에
  "첫 러닝을 마치면 여기에 기록이 쌓입니다." 한 줄과 `/home` 으로 가는 「첫 러닝 시작하기」 CTA 를
  덧붙였다. 새 일러스트는 만들지 않았고(#43 · #44 방침), 버튼 모양은 정본의 주요 CTA
  (`탄천런.dc.html:367` · `:471` — 높이 58 · radius 20 · `#2F6FE8` · 그림자)와 같은 토큰
  (`h-[58px] rounded-xl bg-primary shadow-primary`)이다. 기록이 있을 때의 UI 와 위 두 카드의
  0 표기는 건드리지 않았다.
- **고쳐야 할 곳**: `docs/04-features.md:22` F7 의 「예외」 칸과 `docs/07-screens.md:27` 의 빈 상태
  항목에 「다음 행동(러닝 시작) 안내와 이동 수단을 함께 보인다」를 덧붙인다.

## 2. 기록 탭에서 러닝 시작 화면으로 가는 길이 탭 이동 말고 하나 더 생겼다

- **문서**: `docs/07-screens.md:62` 는 기록 탭 → 러닝 시작 화면 이동을 「탭에서 러닝 시작을
  고른다(**공통 탭 이동**)」 **한 가지로만** 적는다.
- **디자인 · 구현**: 기록이 0건일 때만 보이는 CTA 가 같은 목적지(`/home` = 달리기 탭 = 러닝 시작
  화면)로 가는 두 번째 길이 된다. 하단 탭바는 그대로 유지되므로 기존 이동을 **대체하지 않고**
  빈 상태에서만 지름길을 더한 것이다.
- **고쳐야 할 곳**: `docs/07-screens.md:62` 근처에 「기록 탭(기록 0건 빈 상태) — 빈 상태의 러닝
  시작 CTA 선택 → 러닝 시작 화면」 행을 덧붙인다.
