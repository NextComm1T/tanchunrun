## GPS 안내 카드에 액션 버튼이 하나 더 생겼다

- **문서**: 정본 디자인 `탄천런.dc.html` L724-730 의 GPS 안내 카드에는 문구만 있고
  **버튼이 없다.** `docs/07-screens.md` 홈 달리기 탭의 비준비 상태도 「GPS 확인 중」 하나뿐이다.
- **디자인 · 구현**: `unavailable`(권한은 있는데 좌표를 못 받음) 상태에 **「다시 확인」 버튼**을
  붙여 `useGeolocationReady().retry()` 를 부른다. 정본에 없는 요소라 `denied` 의 「위치정보 설정 보기」
  링크와 같은 토큰 · 같은 크기를 쓴다.
  - 이유: #81 이 이미 「위치 확보 실패 → 문구 + 다시 시도」를 AC 로 정했는데 이 자리에만 빠져 있었다.
    시작 버튼이 `disabled` 라 다른 복구 경로가 없어 새로고침 말고는 빠져나갈 길이 없었다.
  - `denied` 는 브라우저 설정을 고쳐야 풀려서 재측위가 소용없다. 기존 링크 흐름을 그대로 뒀다(#124 소관).
  - 이 divergence 는 `modify/2026-09-16-run-session.md` 2번(비준비 상태 1종 → 3종)의 연장이다.
- **고쳐야 할 곳**: `docs/07-screens.md` 홈 달리기 탭의 상태 목록에 상태별 다음 행동을 적을 때
  `unavailable` 의 행동으로 「다시 확인」을 넣는다. `docs/05-policy.md` P1 도 같은 자리.
