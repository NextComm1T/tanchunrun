# 러닝 진행 — 완전 오프라인 종료 (#147)

## 완전 오프라인에서 종료하면 결과 화면으로 가지 않고 러닝 화면에서 기다린다

- **문서**: `docs/07-screens.md:55` — 「러닝 종료 버튼 클릭 · 종료 처리(자동 저장 · 순위 계산)
  실패(진행 중 → 종료 · **인터넷 끊김 등**)」의 다음 화면이 「결과 화면(오류 상태 · "다시 시도")」이다.
- **디자인 · 구현**: 결과 화면은 서버 렌더라 **완전 오프라인에서는 그 화면 자체에 닿지 못한다** —
  `replace` 하면 RSC 요청이 실패해 브라우저 오류 페이지가 되고, 그 페이지에는 앱 JS 가 없어
  온라인으로 돌아와도 아무것도 진행되지 않는다(#89 2차 실측 F4 · #147). 그래서 이동 전에 도달
  가능한지 한 번 확인하고, 못 나가면 러닝 진행 화면에 남아 「연결되면 자동으로 넘어갑니다」와
  「지금 다시 시도」를 보인 뒤 연결이 돌아오면 그때 결과 화면으로 간다. 종료 intent 를 이동보다
  먼저 durable 하게 남기는 순서(D11)는 그대로다. **API 만 막힌 경우**(서버에는 닿는다)는 문서
  그대로 결과 화면으로 가서 오류 상태 · 다시 시도를 본다.
- **고쳐야 할 곳**: `docs/07-screens.md:55` 의 화면 전이 행 — 「인터넷 끊김 등」을 **서버에 닿지
  못함**(러닝 화면에서 대기)과 **닿았으나 종료 처리 실패**(결과 화면 오류 상태) 두 갈래로 나눠야 한다.
